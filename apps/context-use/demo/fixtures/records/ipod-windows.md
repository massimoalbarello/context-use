# iPod expands to Windows

Research summary, paraphrased for this seed; not the original document.

The announcement adds Windows models using Musicmatch Jukebox and FireWire, with late-August availability planned. Mac models continue with iTunes. The 10GB and 20GB models introduce a touch-sensitive wheel.

Source: [iPod expands to Windows](https://www.apple.com/newsroom/2002/07/17Apple-Unveils-New-iPods/).
