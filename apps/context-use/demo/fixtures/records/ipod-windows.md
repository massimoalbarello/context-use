# Windows iPod: accept a bridge, keep the experience gap visible

Fictional demo · Synced from Granola · 2002-07-17

**Attendees:** Steve Jobs, Tony Fadell, Phil Schiller\
**Time:** 09:00–09:45 UTC

## Choice
Open iPod to Windows customers using Musicmatch Jukebox. Keeping iPod Mac-only would preserve one software path, but would exclude people who want the player and already own a PC.

## Accepted compromise
We own the hardware; the Windows library and synchronization experience depends on Musicmatch. Phil must not describe the Mac and PC setup flows as identical. Tony will collect failures at the software/device handoff with enough detail to reproduce them.

## Follow-up
Steve wants the team to evaluate an Apple-owned Windows music application if the bridge leaves customers managing two experiences. Phil owns the customer language; Tony owns the handoff evidence. Windows support is a decision for this release, not a claim that the compromise is permanent.
