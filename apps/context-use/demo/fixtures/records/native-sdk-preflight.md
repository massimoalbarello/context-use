# Native SDK decision review: answer the gaps without promising a finished platform

Fictional demo · Synced from Granola · 2007-10-16

**Attendees:** Steve Jobs, Scott Forstall, Phil Schiller\
**Time:** 09:00–09:45 UTC

## Evidence
The July developer follow-up identified offline use, device capabilities and richer interfaces as gaps in the web-only launch approach. Scott’s proposal now treats native access and user protection as work that must progress together.

## Alternatives
Stay with web applications and leave those use cases constrained, or commit to a native SDK with time to build a supportable model. Steve chooses the latter. This changes the June approach; it does not mean the June release contained a native SDK.

## Commitment to communicate
Target February 2008 for an SDK for iPhone and iPod touch. Scott owns scope and the protection model; Phil owns the public wording. Distribution and developer details remain work in progress and should not be invented in the announcement.

## Next step
Send the commitment tomorrow. Scott brings scope risks to the next software review; do not confuse announcing a date with delivering the tools.
