# iPhone interaction review: fingers, software and the whole sequence

Fictional demo · Synced from Granola · 2007-01-07

**Attendees:** Steve Jobs, Scott Forstall, Jony Ive, Tony Fadell\
**Time:** 09:00–09:45 UTC

## Evidence brought forward
Tony revisited the September 2005 ROKR debrief: improving a music feature could not repair every handoff in a partner-controlled phone. Scott now demonstrates music, a call, typing and a web page on the same touch interface.

## Decision
Use fingers and software-defined controls instead of a fixed keyboard or stylus. Jony and Scott must evaluate the screen, enclosure and interactions as one product. Steve wants the transition between tasks to be as convincing as each task on its own.

## Rehearsal risks
Typing and zooming need enough time for the audience to understand them. Scott owns a repeatable device state for tomorrow’s full rehearsal; Tony checks the music-to-call transition.

## Unresolved
A successful stage sequence does not prove launch readiness, retail setup or a third-party application model. Keep those as separate commitments.
