# WWDC applications review: web at launch, native questions open

Fictional demo · Synced from Granola · 2007-06-11

**Attendees:** Steve Jobs, Scott Forstall, Phil Schiller\
**Time:** 09:00–09:45 UTC

## Launch decision
Offer third-party web applications using Internet standards. Scott can describe a path developers can use without promising a native SDK before we have a supportable design.

## Tradeoff
Steve wants a dependable phone at launch. Scott warns that web applications will not answer every request for device capabilities, performance or offline use. Phil should present what is available without implying these needs have disappeared.

## Follow-up
Scott owns collecting concrete developer use cases after WWDC. Group them by what prevents the proposed application from working, not by how loudly someone asks for a native SDK. Return with examples in July. No native SDK release date is committed in this meeting.
