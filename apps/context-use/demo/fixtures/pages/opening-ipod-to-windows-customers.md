# Opening iPod to Windows customers

[I](context-use://entity/steve-jobs) accepted the [Musicmatch](context-use://entity/musicmatch-jukebox) bridge so people with [Windows](context-use://entity/windows) PCs can use iPod. The [decision review](context-use://record/ipod-windows) records the compromise: we own the player but depend on another application for the library and synchronization.

This changes the [Mac-only starting point](context-use://page/putting-the-first-ipod-in-my-pocket). Keeping that restriction would preserve one software path and leave interested customers out. I would rather make the compromise explicit than pretend both paths are identical.

[Tony](context-use://entity/tony-fadell) owns collecting reproducible handoff failures. [Phil](context-use://entity/phil-schiller) owns an honest setup explanation. I have asked for an evaluation of our own Windows music application if the bridge leaves people managing two experiences. This release is a step, not a permanent answer.
