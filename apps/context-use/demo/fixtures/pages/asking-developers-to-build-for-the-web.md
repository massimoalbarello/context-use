# Asking developers to build for the web

[I](context-use://entity/steve-jobs) chose web applications for the iPhone launch. The [WWDC applications review](context-use://record/web-apps) records why: give developers a path we can describe now while protecting a dependable phone experience.

[Scott](context-use://entity/scott-forstall) also recorded the limits. Web applications will not answer every need for offline use, device capabilities or performance. I am treating those as open product questions, not as objections that disappear because we picked a launch approach.

The [touch-interface decision](context-use://page/building-a-phone-around-our-fingers) lets software define much of the experience; it makes the question of what others can build consequential. Scott owns collecting concrete use cases for July. [Phil](context-use://entity/phil-schiller) must explain the current offer without implying we have committed to a native SDK date.
