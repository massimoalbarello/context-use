# The boundaries I work across

[I](context-use://entity/steve-jobs) need to remember which kinds of control have helped, and which kinds would get in the way.

The [Windows bridge](context-use://page/opening-ipod-to-windows-customers) and [Motorola partnership](context-use://page/taking-itunes-onto-motorola-phones) bought reach at the cost of seams in the experience. [Our own Windows software](context-use://page/bringing-our-own-itunes-to-windows) closed one. The [ROKR debrief](context-use://page/comparing-nano-and-rokr-with-tony) made a stronger case for owning the phone interaction, while [the AT&T support handoff](context-use://page/preparing-the-first-customer-hour-with-ron) still required cooperation.

[Pixar inside Disney](context-use://page/carrying-my-pixar-work-into-disney) has a different boundary: I want shared interests and distribution without damaging candid creative work. The [decision meeting](context-use://record/pixar-call) and [closing email](context-use://record/pixar-close) explain both the choice and my changed role.

The [native SDK](context-use://page/committing-to-native-applications-for-iphone) now asks me to make control useful to other people. The [iTunes Plus change](context-use://page/lowering-itunes-plus-prices) asks which restrictions and distinctions we can remove. I should not apply yesterday's answer without recovering the problem it solved.
