# Pilot journey map

[Maya Chen](context-use://entity/maya-chen) and [Jun Park](context-use://entity/jun-park) mapped how an [Orbit Labs](context-use://entity/orbit-labs) teammate discovers [Northstar](context-use://entity/northstar), inspects a page, and follows an attached resource.

## Friction points

New users hesitate when labels overlap or controls compete with previews. These observations feed the [mobile navigation review](context-use://page/mobile-navigation-review) and [resource card patterns](context-use://page/resource-card-patterns).
