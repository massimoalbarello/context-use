# Asking developers to build for the web

At WWDC, our [third-party application announcement](context-use://record/web-apps) asks developers to use web standards for [iPhone](context-use://entity/iphone). [I](context-use://entity/steve-jobs) present this as our launch approach to extending the device.

The phone we [unveiled in January](context-use://page/introducing-the-phone-we-built) is approaching sale. This announcement offers web applications, not a native SDK or an App Store.
