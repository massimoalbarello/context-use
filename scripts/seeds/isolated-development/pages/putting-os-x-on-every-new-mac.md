# Putting OS X on every new Mac

On May 21, 2001, we began factory preinstalling [Mac OS X](context-use://entity/mac-os-x) alongside Mac OS 9.1 at [Apple](context-use://entity/apple). Our [announcement](context-use://record/osx-preinstall) keeps Mac OS 9.1 as the default boot system.

[I](context-use://entity/steve-jobs) am taking the [transition](context-use://page/moving-the-mac-to-os-x) to more customers while leaving them a way to use their existing environment. They can choose OS X and switch back. Preinstalling the new system and making it the default are separate steps.
