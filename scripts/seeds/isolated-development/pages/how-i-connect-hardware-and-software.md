# How I connect hardware and software

[I](context-use://entity/steve-jobs) use the customer’s path through a product to connect the work: acquire something, organize it, carry it and use it. [Our player family](context-use://page/taking-our-music-experience-beyond-the-mac), [our store](context-use://page/making-our-store-part-of-the-music-experience) and [our phone](context-use://page/bringing-our-music-work-into-phones) are different views of that path.

This is my organizing lens for the reconstructed workspace. It does not imply that every later product was decided when we introduced the first one.
