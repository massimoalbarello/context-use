# OS X is installed but OS 9 still boots

On May 21, [Apple](context-use://entity/apple) began factory preinstalling [Mac OS X](context-use://entity/mac-os-x) beside Mac OS 9.1. The [source record](context-use://record/osx-preinstall) explicitly says Mac OS 9.1 remained the default boot system.

This matters to [Steve Jobs](context-use://entity/steve-jobs)’s [transition](context-use://page/moving-the-mac-to-os-x): distribution expands before the old environment is displaced. Customers can choose and revert. “Comes with OS X” and “starts in OS X” are different states.
