# Committing to native applications for iPhone

In [my public letter, reproduced by TidBITS](context-use://record/native-sdk), [I](context-use://entity/steve-jobs) commit to an SDK in February 2008 for native third-party applications on [iPhone](context-use://entity/iphone) and [iPod touch](context-use://entity/ipod-touch).

This changes the direction from [our June web-application offer](context-use://page/asking-developers-to-build-for-the-web). The work still lies ahead: I am making a dated commitment, not describing a shipped SDK.
