# Bringing our own iTunes to Windows

[I](context-use://entity/steve-jobs) can now offer PC customers our own [iTunes](context-use://entity/itunes), with store access and iPod synchronization. The [Windows release](context-use://record/itunes-windows) extends the same song-purchasing model to [Windows](context-use://entity/windows).

This replaces the split described in [our earlier Windows iPod plan](context-use://page/opening-ipod-to-windows-customers). My [rehearsal with Phil](context-use://page/rehearsing-our-windows-message-with-phil) is a fictional way to explore how we might explain that change.
