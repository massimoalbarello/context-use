# The store as a place to learn

A useful way to understand [Steve Jobs](context-use://entity/steve-jobs) and [Ron Johnson](context-use://entity/ron-johnson)’s retail work is to ask what a visitor can learn to do. [Apple Retail Stores](context-use://entity/apple-retail-stores) give the hardware-and-software story a place where someone can see a task demonstrated and ask for help.

The [store-format announcement](context-use://record/stores-plan) emphasizes demonstrations, digital-lifestyle solutions and a Genius Bar. That supports this interpretation of the format; it does not establish Steve’s private thoughts or prove that every visitor had the same experience. [The digital-hub model](context-use://page/what-a-digital-hub-connects) explains the connected activities a demonstration can make tangible.

Follow [the dated store story](context-use://page/learning-to-sell-the-whole-experience) for the opening plan and reported results at [Tysons Corner](context-use://entity/tysons-corner) and [Glendale Galleria](context-use://entity/glendale-galleria). This reference note explains the customer-facing idea rather than assigning that idea a new event date.
