# Cube gains CD-RW and iTunes

Research summary, paraphrased for this seed; not the original document.

A new Cube configuration paired a slot-loading CD-RW drive with iTunes. This is a different optical-drive configuration from the DVD-equipped Cube announced in July 2000. Apple continued to describe the fanless design.

Source: [Cube gains CD-RW and iTunes](https://www.apple.com/newsroom/2001/02/22Apple-Introduces-New-Power-Mac-G4-Cube-With-CD-RW-iTunes/).
