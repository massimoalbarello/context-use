# The initial third-party iPhone application offer

Research summary, paraphrased for this seed; not the original document.

Apple invites developers to build web applications for iPhone. The launch approach uses Internet standards; this announcement does not release a native application SDK.

Source: [The initial third-party iPhone application offer](https://www.apple.com/newsroom/2007/06/11iPhone-to-Support-Third-Party-Web-2-0-Applications/).
