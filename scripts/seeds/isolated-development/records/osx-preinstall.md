# Mac OS X preinstalled beside Mac OS 9

Research summary, paraphrased for this seed; not the original document.

Apple confirmed March 24 shipping and began factory preinstallation of both operating systems on May 21. New Macs still booted into Mac OS 9.1 by default; users could switch. Preinstallation did not mean OS X was the default boot system.

Source: [Mac OS X preinstalled beside Mac OS 9](https://www.apple.com/newsroom/2001/05/21Apple-to-Pre-Install-Mac-OS-X-Ahead-of-Schedule/).
