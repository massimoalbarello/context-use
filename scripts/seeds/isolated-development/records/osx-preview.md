# Mac OS X preview and original schedule

Research summary, paraphrased for this seed; not the original document.

Jobs demonstrated Aqua and the Dock. Apple described Darwin, protected memory and preemptive multitasking, with Classic and Carbon migration paths. It expected a commercial release in summer 2000 and standard preinstallation in early 2001.

Source: [Mac OS X preview and original schedule](https://www.apple.com/newsroom/2000/01/05Apple-Unveils-Mac-OS-X/).
