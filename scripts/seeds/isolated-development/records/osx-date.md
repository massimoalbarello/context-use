# Mac OS X receives a March shipping date

Research summary, paraphrased for this seed; not the original document.

Apple set March 24, 2001 availability at $129. It reported over 100,000 public-beta copies shipped and over 75,000 feedback entries. The source describes Classic, Carbon and Cocoa as distinct application paths.

Source: [Mac OS X receives a March shipping date](https://www.apple.com/newsroom/2001/01/09Apples-Mac-OS-X-to-Ship-on-March-24/).
