# Mac OS X public beta opens to users

Research summary, paraphrased for this seed; not the original document.

Apple released a public preview at Apple Expo Paris for $29.95. English, French and German versions were available. Jobs asked users for feedback; the release was explicitly a beta, not the final operating system.

Source: [Mac OS X public beta opens to users](https://www.apple.com/newsroom/2000/09/13Apple-Releases-Mac-OS-X-Public-Beta/).
