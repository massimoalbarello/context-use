# Jobs commits to a native iPhone SDK

Research summary, paraphrased for this seed; not the original document.

TidBITS reproduces Jobs’s dated letter committing to a native SDK in February 2008, also for iPod touch. He frames the work around developer access and user protection. This is a future commitment, not a shipped SDK.
